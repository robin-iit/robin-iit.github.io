# Plain academic portfolio

A deliberately simple academic website using one serif type family, readable text sizes,
a persistent fixed header, and a narrow text column.

## Edit these placeholders
- `[Your Name]`
- `your.email@example.com`
- current position and institution
- academic biography
- publication titles, authors, years and DOI links
- Google Scholar, ORCID and LinkedIn profile URLs

## Publish with GitHub Pages
1. Create a repository named `YOUR-USERNAME.github.io`.
2. Upload `index.html` and `style.css` to the repository root.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. Visit `https://YOUR-USERNAME.github.io`.

To connect a personal domain later, enter it under **Settings → Pages → Custom domain**
and configure the DNS records with your domain registrar.
